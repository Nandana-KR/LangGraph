# LangGraph Basics

A beginner-friendly project demonstrating how to build workflow-based AI applications using LangGraph and Python.

## About The Project

This project demonstrates the fundamentals of LangGraph by creating a simple state-driven workflow graph. The application takes user input, processes it through different graph nodes, and dynamically routes execution using conditional edges.

The project includes:

- State management using TypedDict
- Node creation in LangGraph
- Conditional routing
- Graph visualization
- Workflow execution using LangGraph

The graph simulates a simple activity planning system where the workflow randomly selects between different sports activities such as Cricket or Badminton.

## Features

- State-based workflow execution
- Conditional graph edges
- Multiple connected nodes
- Random decision routing
- Mermaid graph visualization
- Jupyter Notebook implementation

## Technologies Used

- Python
- LangGraph
- Jupyter Notebook
- IPython
- typing_extensions
